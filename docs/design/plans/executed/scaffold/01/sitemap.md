# Sitemap — Sprint LUMEN-01

Site one-page. Toda la información cabe en `/` con anchors internos.

```
/                          ← Hero, navegación, contenido principal
├─ #features               ← Sección Features (CLI / MCP / HTTP / TUI)
├─ #install                ← Sección Install (3 paths)
├─ #support                ← Sección Support / Apoyar (donate widget)
└─ #footer                 ← License, links, bandwidth disclosure
```

## Out of scope (v0.1.0)

- `/docs` — los docs viven en GitHub `docs/` por ahora. Si emerge demanda, se hace en LUMEN-02.
- `/blog` — no hay blog.
- `/changelog` — link al `CHANGELOG.md` en GitHub, no replicado.
- `/sponsors` — no es un Patreon, no necesita panel separado.

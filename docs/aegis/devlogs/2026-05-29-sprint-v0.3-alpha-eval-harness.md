## Resumen

v0.3-α es un release **evaluation-first** (ADR-14): se construyó el harness de calidad de memoria (`seele-eval`, crate #14) que mide recall@k / MRR por categoría contra el pipeline híbrido, y se capturó el **primer baseline auditable de SEELE (v0.2)**. Acompañan: higiene de docs (README→v0.2, doc-drift de `int_id`/crates, CHANGELOG), un fix de correctitud real (silent-drop de `int_id` en el path de import), la migración `embeddings_meta` (prerequisito duro de A2/B3), y la investigación de footprint del binario (ADR-15). El baseline ya orienta la inversión: **paraphrase + multi-hop son los puntos flojos del RRF puro; single-fact/temporal están saturados.**

## Decisiones técnicas

- `as_i64` mapea el tail aleatorio (no el timestamp); fresh-save reintenta, import no puede → se reporta la colisión (Gate 1 redirect).
- `ingest` usa `save_raw` (no `save`) para no colapsar items que comparten `topic_key` (p.ej. el par de knowledge-update).
- `embeddings_meta` FK a `observations(id)` (la auditoría/ADR génesis decían "memories", nombre legacy).
- `expected_ids` laxo (decisión del usuario): knowledge-update acepta viejo+vigente.
- `longmemeval-subset` = suite casera (decisión del usuario), no el dataset académico.
- Baseline capturado con modelo local (`from_local_dir`) por el quirk de `hf-hub` del entorno.

## Incidentes durante la ejecución

- **Disco lleno (0 GB libres / 475 GB usados)**: un rebuild chocó contra disco lleno. Mitigado: borrar `target/release` (artefactos de bloat) + `cargo clean` → ~8.4 GB liberados. **El disco del sistema sigue crítico** — conviene liberar fuera del proyecto.
- **LNK1318 (PDB LIMIT/FILE_SYSTEM)**: el link del test-exe (ONNX estático → PDB gigante) fallaba. Mitigado con `CARGO_PROFILE_TEST_DEBUG=0` (sin debuginfo → sin PDB).
- **`hf-hub` falla** ("RelativeUrlWithoutBase") en el sandbox e ignora `HF_ENDPOINT`. No es código (HF alcanzable, modelo público). Workaround: descarga manual + `from_local_dir` (coherente con los tests ONNX `#[ignore]` "run locally").
- **LNK1104 (.exe lockeado)**: Defender escaneando el binario ML. Mitigado: matar proceso + borrar exe stale + retry.
